Why Multi Theft Auto

The game was always bigger than SA-MP

Scavenge & Survive spent a decade working around its platform: tracers built from objects, ziplines made of dozens of poles, hats that fit seventeen skins, a world that had to be re-rolled every five hours. Multi Theft Auto removes the workarounds. Here is what the engine gives a survival server, each point paired with the thing in Reborn that only exists because of it.

wiki.multitheftauto.com

Open source and still released

MTA:SA has been open source since 2008 and the project is still releasing: 1.6.0 shipped in June 2023 and nightly builds keep adding functions. SA-MP's last client, 0.3.7, dates from 2015; open.mp keeps those servers running but is bound to that client's feature set.

Client-side buildings, 3D models drawn in the UI with real lighting, and the bone-attachment hook this port's apparel uses all arrived in 2023 or later. The port targets what the engine does today, not what it did in 2015.

Scripting introduction

Lua on both sides, in resources

Server and client are both scripted in Lua and organised in resources that start, stop and talk to each other independently. Pawn runs only on the server and compiles to one gamemode.

32 resources, one per domain, that share state only through MariaDB: any one of them restarts on its own and rebuilds from the database. Pure game logic lives in shared files the client and server both run.

engineLoadDFF

Your own models

A script can load DFF, TXD and COL files and replace or allocate models on the client, with custom IMG containers since 1.6. SA-MP 0.3.DL added model downloads late and few servers used them.

The towable Airstream, twelve Bobcat salvage parts, nine cut hats, 22 hatless skin twins, fitted house doors, glazed windows, enterable trailers and cabins, the camper stove, GTA's own boxes as items: all built in Blender and shipped as resources.

createBuilding

The world is built on the client

Buildings are created client-side with shadows and glass, more cheaply than objects, and the streamer handles a thousand objects at once. SA-MP needed a streamer plugin on the server for everything.

221 upstream maps, 23,211 objects, become buildings on each client in about 1.3 s on join, spread over frames so nothing stutters, with the 209 SA-MP-only models shipped alongside.

dxDrawModel3D

A client that can draw

Immediate-mode dx drawing, render targets, fonts, SVG, shaders, 3D models in the UI, and a CEF browser and CEGUI for forms. SA-MP had textdraws and fixed dialogs.

The HUD, inventory, keypad, radio panel, watch, death screen and driver's dashboard were measured from 18 videos of the original and rebuilt to look like home, with live 3D previews of the items you wear and animated flames on the stove from a shader.

onClientPlayerDamage

Sync you can build rules on

Hits are reported per limb, client damage can be cancelled and re-decided, and health set by the server cannot be overwritten by a stale client packet. MTA calls it the best GTA synchronisation there is.

The victim's client reports a hit, the server matches it against the shooter's recent shots, checks range and rate, and computes the wound from calibre, ammo type, distance and body part. No client decides its own health.

Anti-cheat guide

Anti-cheat and serials

A built-in anti-cheat blocks trainers, injected code and speed or health tools; every client has a serial; element data can be locked so a client cannot forge it.

Fourteen server checks on gameplay values on top, 31 hacker traps, bans by name, IP and serial that persist in the database, and a client that never sets element data at all.

bindKey

Keys, voice, effects, trailers

Every action is a bind the player can change in the client's settings. Built-in voice chat. Engine particle effects. Native trailer hitching. Dimensions and interiors.

Rebind F, N, H or R in MTA Settings. Proximity voice with a talking indicator. Crate smoke and flares as real effects. A zipline rope that is one line, not forty poles. The Airstream hitches with the game's own physics.

The landscape, fairly

SA-MP, open.mp and MTA in 2026

SA-MP's codebase is frozen; its network is alive and niche, and mostly roleplay. open.mp is the community continuation: fully backwards-compatible, running the existing servers and Pawn scripts, and still in development. Multi Theft Auto never depended on either and has its own master list, its own client and a GPL source tree on GitHub.

In December 2025 Take-Two filed a DMCA takedown against MTA's repository; the team filed a counter-notice and the repository was restored. Tolerated is not the same as sanctioned, and that is true of every San Andreas multiplayer.

All three need the original PC release of GTA: San Andreas. None works with the Definitive Edition.

Sources: GTA Intel, "San Andreas multiplayer in 2026", Wikipedia, multitheftauto.com.
