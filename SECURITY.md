# Security policy

Supported: the `main` branch and the latest release. Report vulnerabilities (auth bypass, SQL injection,
client-trusted events, item duplication exploits) privately through
[GitHub Security Advisories](https://github.com/VIRUXE/scavengesurvive-mta/security/advisories/new).
Do not open public issues for them. Expect an answer within 7 days; fixes ship as a patch release
and the advisory is published after the release.
