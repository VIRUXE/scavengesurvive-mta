## Bugs found and fixed (`6592257`)

1. **`/kick`, `/ban`, `/mute`, `/unmute`, `/restart` never reached the staff resource.** They are MTA console
   commands, or names the stock Default ACL denies to every player as `command.<name>`. The first
   `rcon cmd VIRUXE ban …` returned `false` with no row and no log line. Fix: the client forwards those five with
   their arguments through `staffCommandIssued`, the server cancels `onPlayerCommand` for them (so MTA neither
   runs its own kick/ban nor prints "ACL: Access denied"), `logic.CHAT_BRIDGED` names the set, and
   `exports.staff:runCommand` serves dev's `cmd` verb.
2. **Offline-account replies went to the server log.** `ctx.lookupAccount` dropped the actor its callers passed,
   so `/ban <offline>`, `/aliases`, `/history` and `/ip <offline>` answered a nil actor: `scripts.log` showed
   `Bad argument @ 'getElementType' [Expected element at argument 1, got nil]` and
   `bad argument #2 to 'format' (string expected, got boolean)`, and the ban row carried `by_name = "0"`.
3. **The ban list's Unban row did nothing.** It called `executeCommandHandler`, which needs the
   `function.executeCommandHandler` right that only `dev` requests: `scripts.log` had
   `Access denied @ 'executeCommandHandler' [staff/server/bans.lua]`. It now calls the shared unban routine and
   refreshes (or closes) the list when the procedure answers.

## MTA facts learned (also in the spec's Appendix B)

- `CConsole::HandleInput`: `onPlayerCommand` fires first with the command name only; cancelling it skips
  everything else. Then the hardcoded command list is consulted before script handlers, gated by the
  `command.<name>` right on the player's MTA account (guest = Everyone = Default ACL) with "ACL: Access denied"
  echoed to the chat; script handlers run only when no hardcoded name matches.
- `CRegisteredCommands::ProcessCommand` (also the path of `executeCommandHandler`) checks the same
  `command.<name>` right, default allowed unless the handler was registered restricted. The stock Default ACL
  denies kick, ban, mute, unmute, restart, start, stop, stopall, refresh, shutdown, addaccount, debugscript and
  more, so a resource cannot own those names for players.
- `executeCommandHandler` from a resource needs `function.executeCommandHandler`; it accepts a player, not the
  console element.
- `takePlayerScreenShot` captures dx drawing but never the chat box.
