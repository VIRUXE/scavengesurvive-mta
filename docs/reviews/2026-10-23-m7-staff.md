## Not verified live yet (needs a server restart through `run-local.ps1`)

The live server was in use by the apparel session (player `VIRUXE`, resources `items`/`character`/`data`/`dev`
must not restart), and `staff` cannot start on the running server before `run-local.ps1` rebuilds the
`ScavengeSurvive` ACL group (`resource.staff` + `function.kickPlayer` + `function.restartResource`): without it
the resource dies at `loadstring`. `auth` and `weapons` were not restarted either, so the join-time ban check,
the whitelist gate and duty immunity run only in the unit tests so far. Smoke steps 22 a-h in
`docs/mvp-smoke-checklist.md` cover them; the two-client steps (kick request, spectate, duty immunity, mute
seen by the other player) need the second PC that #26 is also waiting for.
