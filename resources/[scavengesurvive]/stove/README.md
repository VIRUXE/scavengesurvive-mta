# Stove

Compact built-in camper range, rebuilt in Blender after GTA Scout reference discovery. Cream enamel, brushed stainless trim, a smoked oven window, compact pan grids and four independent gas burners. The fifth front knob is the visual oven thermostat; oven operation is not implemented.

The stove is approximately 0.525 m wide × 0.577 m deep (including the handle) × 0.630 m high. Position the bottom at counter height minus 0.575 m to align the cooktop lip with a surrounding counter. Start the `stove` resource, then use these **server-side exports** from another resource:

```lua
local stove = exports.stove:createStove(100, 200, 10, 90, 0, 0)
-- Arguments: x, y, bottom Z, heading (optional), interior (optional), dimension (optional).
if stove then
    exports.stove:setStoveBurner(stove, 1, 1.0) -- front left, full flame
    exports.stove:setStoveBurner(stove, 2, 0.5) -- front right, half flame
    exports.stove:setStoveBurner(stove, 3, 0.0) -- rear left, off
    exports.stove:setStoveBurner(stove, 4, 0.8) -- rear right
    local intensity = exports.stove:getStoveBurner(stove, 2)
    exports.stove:setStoveBurners(stove, { 0, 0, 0, 0 }) -- switch all off
    -- exports.stove:destroyStove(stove)
end
```

Burner indices are viewed from the stove front (-Y at zero rotation). Intensity is a finite number between 0 and 1 inclusive. All stoves start off; invalid arguments return `false`, with no partial changes to the four burner values. Setters return `true` on success. Only stoves created by this resource are accepted.

The server owns the synchronized burner values (`stove:burners`, client changes denied). There are no remotely callable control events. Late joiners receive current state through element data. Streamed clients create an attached local visual using a requested model ID; the original native 2417 object remains invisible with collision disabled on that client, while the local visual uses the matching compact COL3 body box. Original anchor visibility and collision settings are restored when the local visual is removed. Ordinary native cooker models are not replaced. Use normal server element functions to move/rotate the returned object or set its interior/dimension. Keep scale at 1; scaled stoves are not supported.

Each burner draws twelve animated blue jets with a procedural additive shader. Intensity controls jet height and width; zero draws no flames. Jets use the stove's transform, are depth-tested, respect interior/dimension, and are culled beyond 40 metres. Shader failure logs an error and leaves the stove visible. Stopping the resource frees its requested model; streaming out removes local visuals. Effects are visual only: cooking, heat damage, fuel usage and persistence are not implemented.

Files `stove.dff`, `stove.txd` and `stove.col` are generated by `tools/build_camper_stove.py`. The model has 13,592 triangles in 86 geometry pieces, six locally generated surface textures, and one collision box. GTA Scout was used to inspect the original cooker candidates before the camper-specific rebuild.

Build with `blender --factory-startup -b -t 4 --python tools/build_camper_stove.py`. Set `GTA_SCOUT_PATH` if the local Scout checkout is elsewhere. The helper `tools/camper_stove_flames.py` creates the independent preview flame rig. Outputs go to Scout’s ignored `output/stove-camper-20261102/` directory, and game assets are copied into this resource. The cabinet surrounds, counter and trailer wall are preview scenery and are excluded from the game exports.

The matching `stove-camper.blend` has a `Stove_Control` object with four 0–1 properties named `burner_1` through `burner_4`. Run its embedded `stove_controls.py` text, then call `set_burner(1, 0.5)` from Python. All flame mesh visibility, scale, flicker and preview lights follow these values. Preview flame geometry is separate from the exported static stove: MTA renders its own procedural flames.

Validation: Lua 5.1 parsing, StyLua and Luacheck pass; all manifest paths exist. DFF/TXD/COL were parsed again after export; every DFF texture reference exists in the TXD, and the collision has one correctly sized body box. The HLSL pixel function compiles with glslang (this does not verify the D3D9 technique or MTA rendering). Blender's evaluated drivers were checked at off, half and full power and a four-burner preview was rendered. The resource has not been started or visually checked in a running MTA client.

MTA API references: [material lines](https://wiki.multitheftauto.com/wiki/DxDrawMaterialLine3D), [element transforms](https://wiki.multitheftauto.com/wiki/GetElementMatrix), [protected element data](https://wiki.multitheftauto.com/wiki/SetElementData), [collision state](https://wiki.multitheftauto.com/wiki/GetElementCollisionsEnabled).
